Windgram is open infrastructure for turning model output into inspectable,
versioned profile documents and rendering those documents wherever a club or
pilot chooses to publish them. Choose the outcome closest to yours.

## Four starting paths

| You want to… | Start here | You will produce |
| --- | --- | --- |
| Publish for a club | [Configure launches](/docs/publish/configure-launches/) | Static model manifests and profile JSON on infrastructure you control |
| Integrate with TypeScript | [Render a first windgram](/docs/typescript/render-first-windgram/) | A validated scene graph, self-contained SVG and key, typed findings, or cross-model comparison |
| Contribute to the pipeline | [Pipeline architecture](/docs/python/pipeline-architecture/) | A tested source, contract, builder, scenario, or documentation change |
| Learn the technical ideas | [Reading a windgram](/docs/learn/reading-a-windgram/) | A working model of the chart, its units, derivations, and uncertainty |
